Фронтенд подключён к локальному API

Архив datathon_ketnavr-main.zip совпадает с frontend из исходной main после
нормализации переводов строк. Дизайн и локальные библиотеки разработчика сохранены.

Реализовано:
- UI и API с одного origin, по умолчанию http://127.0.0.1:8001.
- POST multipart file, X-API-Key, опрос GET jobs, 5-минутный лимит.
- API-ключ только в памяти страницы, без включения в исходники и URL.
- MOV меньше 64 МиБ, сервер проверяет длительность до 180 секунд.
- Отдельные сообщения для сбоев модели, тайм-аутов, памяти и загрузки.
- События, кадры JPEG, время с миллисекундами, проверенные источники.
- При отсутствии подтверждённого источника — явная проверка регламента.
- PDF по всем событиям; base64-кадры декодируются локально без fetch(data:).
- Прекращение ожидания отменяет браузерный опрос; сервер может продолжать работу.
- Статические маршруты имеют явный список. Ключи, data и config не раздаются.
- Запускатель отличает новый ForteLens от прежнего диагностического сайта.

Проверено вручную в браузере на отдельном синтетическом сервере:
положительный ответ, источник verified, отсутствие источника, отрицательный ответ,
сброс старого отчёта, ошибка памяти без ложного no_violation, сброс ключа при
обновлении, кадры и таймкод 00:01.250, успешное скачивание PDF.
Синтетические данные не являются проверкой точности AI.

Проверено через настоящий локальный API с нейтральным именем upload.mov:
- X-13, 65,3 с: failed model_invalid_output за 120,625 с после ограниченной
  повторной проверки. Вердикт не подставлен. Это ошибка модели, не успешный анализ.
- X-29, 17,3 с: done no_violation за 26,531 с; совпадает с отрицательной меткой.
  Событий нет, проверка реальных кадров-доказательств в этом прогоне неприменима.

15 ресурсов UI получили HTTP 200; приватные пути — 404; запрос jobs без ключа — 401.
Проверены синтаксис изменённых JS/Python, уникальность HTML id и git diff --check.
