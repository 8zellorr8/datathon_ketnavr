Локальный сайт по Wi-Fi

На ноутбуке с моделью: Start-LAN.cmd (Windows).
Другие ОС: python3 Start-ForteBank.py --lan
После первой установки возможен запуск с --offline.

Остальные устройства подключаются к той же Wi-Fi сети и открывают адрес,
напечатанный запускателем. Им не нужны Ollama, Python или видеокарта.
При нескольких адресах выбирайте адрес Wi-Fi адаптера с основным шлюзом.
Оставьте окно запуска открытым. Одновременно анализируется одно видео;
ещё одно может ожидать. Модель Ollama слушает только 127.0.0.1.

Ввод API-ключа на сайте не нужен: браузер получает HttpOnly SameSite=Strict
сессию. Результат доступен только отправившей его сессии. Обновление страницы
создаёт новую сессию. Служебный /api/v1 API сохраняет X-API-Key по требованиям
кейса; ключ создаётся автоматически в data/runtime/api-key.txt.

Доступ открыт участникам вашей локальной сети. Используйте доверенную сеть.
Публичная публикация и перенаправление портов роутера не настраиваются.
Если другое устройство не подключается, проверьте изоляцию клиентов Wi-Fi
и разрешение TCP-порта сайта в брандмауэре для вашей доверенной сети.
Не отключайте брандмауэр целиком. IP может измениться после смены сети.
