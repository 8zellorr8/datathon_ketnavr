ForteBank — запуск на другом компьютере

Передавайте обновлённую рабочую папку ForteBank, в которой есть
Start-ForteBank.py и Start-ForteBank.cmd, а не исходный архив партнёра.

ЧТО УСТАНОВИТЬ ОДИН РАЗ

1. Python 3.10 или новее, 64 бита. Рекомендуется Python 3.12.
   Windows: https://www.python.org/downloads/windows/
   При установке Windows включите Add Python to PATH.
   На Linux/macOS можно использовать системный менеджер пакетов.

2. Ollama для своей операционной системы: https://ollama.com/download
   Для NVIDIA нужен установленный драйвер видеокарты.

ПЕРВЫЙ ЗАПУСК

Windows:
   Дважды нажмите Start-ForteBank.cmd в папке проекта.
   Либо в PowerShell из этой папки:
   .\Start-ForteBank.cmd

Linux:
   Откройте терминал в папке проекта:
   sh ./Start-ForteBank.sh

macOS:
   Откройте терминал в папке проекта:
   sh ./Start-ForteBank.sh
   Для запуска через Finder файл Start-ForteBank.command должен иметь право
   исполнения: chmod +x Start-ForteBank.command

Обёртки вызывают общий локальный запускатель Start-ForteBank.py.
Он проверяет окружение и характеристики этого компьютера, а затем готовит
локальный запуск. Не требуется указывать чужой путь C:\Users\YOUR_USER.
Оставьте окно запускателя открытым. Ссылку на сайт и расположение ключа API
смотрите в его выводе. После остановки запускателя сервер недоступен.

Первый запуск требует интернета для загрузки зависимостей и весов модели.
Дальнейшая обработка использует локальные файлы и локальную Ollama.
Видео, кадры и их описания не отправляются во внешние AI-сервисы.
Публичная публикация этим запуском не выполняется.

ЧТО ПЕРЕДАВАТЬ

Обязательно:
   forte_ai/, static/, config/, tests/, requirements.txt,
   Start-ForteBank.py, portable_hardware.py, portable_data.py и файлы Start-ForteBank.*,
   README.md, VALIDATION.md и docs/.

Для работы с исходным датасетом и повторной оценки:
   data/videos/, data/labels_full.xlsx, data/splits.json,
   data/manifest.json, data/dataset_audit.json и Prepare-Data.ps1.
   Запускатель обновляет пути manifest.json, только если SHA-256 всех
   приложенных роликов совпадает с сохранёнными значениями. Старый manifest
   сохраняется в data/runtime/portable/backups/. При пропущенных или
   изменённых видео автоматический перенос откладывается без изменения файла.
   Обычная загрузка нового .mov через сайт не требует таблицы и manifest.

Для продолжения подготовки обучающих примеров:
   training/ целиком, включая подтверждённые ответы и обратную связь.
   Ручные исправления данных не означают, что веса уже дообучены.

Не передавайте:
   .venv/ и .venv-portable*/ — окружение создаётся отдельно для каждого компьютера;
   data/runtime/ — временные видео, результаты заданий и личный API-ключ;
   .env и другие секреты;
   __pycache__/ и *.pyc.

results/ не нужен для запуска. При необходимости передайте его отдельно
как отчёт о прежних проверках, а не как ответы для анализа новых видео.
Веса Ollama загружаются отдельно для нового компьютера.

ДАННЫЕ И РАЗДЕЛЕНИЕ

Автоматический перенос manifest.json не меняет labels, группы и splits.json.
Папка training/ сохраняется. Перед обучением отдельно проверьте и обновите
пути в review/export и сведения о происхождении обучающих примеров.

Ручной Prepare-Data.ps1 обновляет абсолютные пути, а также заново записывает
manifest.json, dataset_audit.json и splits.json. До его запуска сохраните
копию splits.json и training/. Для прежних 42 неизменённых записей разбиение
воспроизводится с тем же seed. Если изменились ролики, метки или группы,
сравните старое и новое разбиение; не переносите отложенные ролики в обучение.

РАЗНОЕ ОБОРУДОВАНИЕ

Характеристики могут влиять на скорость и использование памяти.
Запуск на CPU может быть значительно медленнее, чем на совместимой GPU.
Наличие сайта само по себе не подтверждает работу модели и качество AI.
После переноса время и использование GPU нужно измерить на его компьютере
при реальном анализе: запускатель сам видео не обрабатывает.
В текущем прототипе качество Qwen недостаточно для сдачи. Автоматический
запуск на другом компьютере не исправляет ошибки распознавания.

Модель предобучена; дообучение её весов на наших видео пока не выполнялось.

ПАРАМЕТРЫ

Только диагностика, без установки и запуска сервисов:
   python Start-ForteBank.py --check

После первого полного запуска, без скачиваний и установок:
   python Start-ForteBank.py --offline

Запуск без открытия браузера:
   python Start-ForteBank.py --no-browser

Для отдельного экземпляра, если обычные порты уже заняты:
   python Start-ForteBank.py --port 8002 --model-port 11436

Принудительный CPU на Windows/Linux, с отдельными свободными портами:
   python Start-ForteBank.py --cpu --port 8002 --model-port 11436
Этот флаг на macOS отклоняется: автоматический выбор Metal/CPU остаётся доступен.

Автопрофиль выбирает кеш RAM 128 или 512 МиБ, один параллельный запрос,
сохраняет модель Qwen3-VL-2B, контекст и разрешение кадров. Поддерживаемую
GPU и размещение весов выбирает сама Ollama. При повторном использовании
уже запущенной Ollama её параметры памяти не изменяются.

Если сайт уже работает на обычном порту, повторный запуск только откроет
существующий сайт и явно сообщит, что новая конфигурация не применялась.
Отключение интернета физически на другом компьютере ещё не проверено.
