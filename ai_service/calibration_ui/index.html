Точная разметка входной двери

Это подготовка примеров для исправления детектора. Итог анализа модели здесь не меняется. Видео читается прямо с вашего компьютера и никуда не загружается.

  1. Выберите видео, остановите на нужном моменте и нажмите «Взять кадр».
  2. На кадре обведите входную дверь кабинета, включая створку и проём.
  3. Укажите состояние двери и занят ли сотрудник работой. Если не уверены, выберите «Неясно».
  4. Добавьте наблюдение. Для одного состояния желательно 2–3 кадра в разные моменты. Затем сохраните JSON.

Наблюдения

    Сохраняются только имя файла, секунды, координаты и ваши отметки. Кадры и видео в JSON не входят. Примеры из отложенной test-части сюда не добавляйте.
