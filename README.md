# Datathon Ketnavr — ForteLens

## Локальное AI-ядро и API в ветке test1

В `ai_service/` добавлены локальный анализатор Ollama/Qwen, API, диагностический
интерфейс, переносимые запускатели и проверки. Код взят из рабочей версии команды.
Точность распознавания пока недостаточна для сдачи; пропуск X-33 ещё не исправлен.

Быстрый запуск из корня репозитория (нужны Python 3.10+ и Ollama):

```powershell
cd ai_service
python Start-ForteBank.py
```

Windows также поддерживает запуск `ai_service/Start-ForteBank.cmd`.
Диагностический сайт и API: `http://127.0.0.1:8001`, модель: `127.0.0.1:11435`.
Веса подготавливаются локально запускателем, видео загружается через форму.
Ключ создаётся в `ai_service/data/runtime/api-key.txt` и вводится в форму локально.

Фронтенд разработчика сохранён в `frontend/dist/`. Его адаптер
`frontend/dist/analysis-client.js` пока остаётся заглушкой; подключение нового
фронтенда к API — отдельный следующий шаг. Запуск AI сейчас открывает собственный
диагностический интерфейс.

Подробности: [AI README](ai_service/README.md),
[состояние детектора двери](ai_service/docs/DOOR_DETECTOR_STATUS.txt).

Фронтенд для кейса ForteBank: загрузка видео, просмотр найденных нарушений и общий PDF-отчёт.

## Быстрый запуск

Из корня репозитория:

```bash
python -m http.server 8080 --directory frontend/dist
```

Откройте `http://localhost:8080`.

Сборка и установка npm-зависимостей не нужны. Библиотеки PDF и шрифты включены локально. Для экспорта PDF запускайте сайт через HTTP/HTTPS, а не через `file://`.

## Текущая версия

- Первая страница — выбор видео и состояние проверки.
- Кнопка «Посмотреть нарушение» доступна только при завершённом положительном результате.
- Вторая страница — все события: кадры → время → описание → акт → точный пункт → ссылка.
- PDF-экспорт всех событий в один документ.
- ИИ и сервер анализа ещё не подключены. Для обычных видео запуск анализа пока отключён.

Для проверки интерфейса без ИИ откройте `http://localhost:8080/?demo=1`, загрузите учебный пример и запустите его проверку. Демонстрационные результаты не относятся к загружаемым видео.
