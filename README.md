# Datathon Ketnavr — ForteLens

Фронтенд для кейса ForteBank: загрузка видео, просмотр найденных нарушений и общий PDF-отчёт.

## Быстрый запуск

Из корня репозитория:

```bash
python -m http.server 8080 --directory frontend/dist
```

Откройте `http://localhost:8080`.

Сборка и установка npm-зависимостей не нужны. Библиотеки PDF и шрифты включены локально. Для экспорта PDF запускайте сайт через HTTP/HTTPS, а не через `file://`.

## Текущая версия

- Первая страница — выбор видео и состояние проверки.
- Кнопка «Посмотреть нарушение» доступна только при завершённом положительном результате.
- Вторая страница — все события: кадры → время → описание → акт → точный пункт → ссылка.
- PDF-экспорт всех событий в один документ.
- ИИ и сервер анализа ещё не подключены. Для обычных видео запуск анализа пока отключён.

Для проверки интерфейса без ИИ откройте `http://localhost:8080/?demo=1`, загрузите учебный пример и запустите его проверку. Демонстрационные результаты не относятся к загружаемым видео.
