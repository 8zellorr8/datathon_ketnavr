# Datathon Ketnavr — ForteLens

Локальный сервис анализа кассовых видео: фронтенд разработчика, Python API и Qwen
через Ollama. Интерфейс и API работают с одного адреса, модель остаётся на компьютере.

## Доступ через Wi-Fi

На ноутбуке с ИИ запустите `ai_service/Start-LAN.cmd` или
`python ai_service/Start-ForteBank.py --lan`.
Откройте напечатанный адрес Wi-Fi на телефоне или другом компьютере в той же сети.
На клиентских устройствах достаточно браузера. Ollama остаётся на localhost.
Если Windows блокирует соединение, запустите `ai_service/Enable-WiFi.cmd`
от имени администратора: правило ограничено локальной подсетью и портом 8001.
Подробнее: [локальная сеть](ai_service/docs/LOCAL_WIFI.txt).

## Запуск

Нужны установленный 64-битный Python 3.10+ (рекомендуется 3.12) и Ollama.
Из корня репозитория:

```powershell
cd ai_service
python Start-ForteBank.py
```

Windows: также можно открыть `ai_service/Start-ForteBank.cmd`.
Запускатель определяет систему и память, готовит зависимости и локальные веса.
После подготовки интернет для обработки видео не требуется.

1. Открыть http://127.0.0.1:8001.
2. Браузер получит локальную сессию автоматически; вводить API-ключ не нужно.
3. Выбрать MOV меньше 64 МиБ и до 180 секунд, нажать «Проверить видео».
4. Дождаться завершения. Если найдены события, открыть кадры и общий PDF.

Служебный ключ API хранится в data/runtime/api-key.txt и не передаётся браузеру. Ollama слушает `127.0.0.1:11435`.
Один worker обрабатывает видео, ещё одно может ожидать. Общий API-дедлайн — 5 минут.
«Прекратить ожидание» останавливает браузерный опрос; серверная задача может продолжаться.
Ошибка, timeout и нехватка памяти показываются отдельно от отрицательного результата.

## Статус качества

**Качество AI пока недостаточно для сдачи.** Подключение фронтенда не дообучает модель.
Проверяются только настроенные категории; пропуск X-33 ещё не исправлен.
Отрицательный ответ не подтверждает отсутствие всех нарушений.
Проверенный источник не означает окончательного юридического вывода.
События без подтверждённого основания помечаются «Нужна проверка регламента».

Видео, локальные веса, runtime-ключи и разметка готовятся и хранятся локально.
Датасет не требуется для загрузки нового видео через форму.
Публичный URL/HTTPS — отдельный этап, локальный сервер привязан к loopback.

## Структура

- `frontend/dist/` — интерфейс, API-адаптер, PDF, локальные библиотеки и шрифты.
- `backend/` — бэкенд на FastAPI + Uvicorn: классы сервиса, адаптера ИИ, репозитория и справочник актов.
- `backend/catalogue.py` — Python dictionaries `ACTS` и `REGULATIONS`: 12 типов событий, 6 подтверждённых нормативных оснований.
- `ai_service/` — анализатор, визуальные критерии, очередь задач, multipart-парсер и переносимые запускатели.
- `ai_service/calibration_ui/` — отдельная локальная разметка области двери.

## API

- `POST /api/v1/analyze`: multipart/form-data, поле `file` → `job_id`.
- `GET /api/v1/jobs/{job_id}`: processing / done / failed.
- `GET /api/v1/regulations` — весь справочник; `GET /api/v1/regulations/{rule_id}` — одна запись.
- `X-API-Key` обязателен для `/api/v1/*`. Сайт использует `/ui/api/v1/*` с HttpOnly-сессией.
- `GET /health` — доступность HTTP-сервера, без проверки готовности модели.
- `/docs` — Swagger UI FastAPI, `/openapi.json` — схема API.

Бэкенд сопоставляет **точный `rule_id` → запись справочника → акт/пункт/ссылка**.
Запросы к сайтам законов во время анализа не нужны. Источник из ответа ИИ заменяется
данными справочника. Неизвестный тип или неподтверждённое наблюдение остаётся в отчёте
с пометкой о проверке регламента и без придуманной статьи. PDF по всем событиям
создаётся существующим фронтендом.

## Проверка бэкенда

Из корня репозитория, без запуска модели:

```powershell
python -m backend check
python -m unittest discover -s backend/tests -v
```

Старый отдельный `python -m forte_ai serve` запускает только AI-транспорт.
Для сайта со справочником используйте `Start-ForteBank.py` или `python -m backend serve`.
Подробности настройки ключа, архитектуры и API — в [backend/README.md](backend/README.md).

## Демо и документация

http://127.0.0.1:8001/?demo=1 включает отдельные учебные примеры интерфейса.
Демо не используется как ответ на загруженные видео и не подменяет ошибку AI.
Статический сервер `python -m http.server 8080 --directory frontend/dist`
подходит только для просмотра дизайна/демо: API на нём отсутствует.
