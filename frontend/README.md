# ForteLens — фронтенд

Две страницы на HTML, CSS и JavaScript. Сервер анализа и ИИ ещё не подключены.

## Пользовательский сценарий

1. На первой странице — выбор одного видео MOV, MP4 или WebM до 100 МБ.
2. После подключения ИИ кнопка «Проверить видео» будет запускать анализ. Сейчас для обычных файлов она отключена.
3. «Посмотреть нарушение» появляется и становится активной только после завершённого результата `violation` с непустым списком событий.
4. На второй странице все события идут подряд: кадры → время → краткое описание → акт → точный пункт → ссылка.
5. «Скачать PDF» формирует один документ со всеми событиями. Кириллица, изображения, ссылки и перенос страниц поддерживаются.

При отсутствии нарушений, ошибке, отмене и выборе нового файла отчёт недоступен. Прямой переход на `#report` без результата возвращает на страницу загрузки. После перезагрузки страницы результат не сохраняется.

## Запуск на компьютере

Из папки проекта запустите статический сервер:

```powershell
python -m http.server 8080 --directory dist
```

Откройте `http://localhost:8080`. Сборка и npm install не нужны. Для PDF нужен HTTP/HTTPS, потому что браузер загружает локальные файлы шрифтов; простое открытие index.html через file:// для экспорта PDF не подходит.

## Проверка интерфейса без ИИ

Откройте `http://localhost:8080/?demo=1`. Внизу появится отдельная тестовая панель, которой нет на обычной странице.

- Выберите сценарий: два нарушения, отсутствие нарушений или ошибка.
- Нажмите «Загрузить учебный пример», затем «Проверить учебный пример».
- При положительном результате нажмите «Посмотреть нарушение».

Демо использует только учебные схемы и явно помеченный отчёт. Результаты не относятся к загружаемым файлам. Параметр demo — инструмент проверки интерфейса, а не проверка видео.

## Файлы

- `dist/index.html`, `dist/styles.css` — две страницы и адаптивный дизайн.
- `dist/app.js` — состояния, проверка результата, доступ к отчёту, обработчики интерфейса.
- `dist/analysis-client.js` — место подключения будущего API.
- `dist/demo.js` — независимые тестовые данные.
- `dist/pdf-export.js` — сборка PDF в браузере.
- `dist/vendor/`, `dist/assets/fonts/` — локальные библиотеки, шрифты и лицензии. CDN не используется.

Дальнейшее подключение сервера описано в `INTEGRATION.md`.

## Проверка этой версии

В браузере проверены обычный первый экран, положительный и пустой результаты, ошибка, отмена и защита перехода к отчёту. PDF-генератор проверен отдельно на двухстраничном и длинном шестистраничном отчётах: кириллица, ссылки, дробные таймкоды, перенос текста и отмена экспорта. Автоматические выбор файла и скачивание через браузер были заблокированы его проверкой разрешений; полный цикл SVG → PDF → загрузка на устройство в этой среде не подтверждён.

ForteLens — прототип команды для кейса; не официальный сервис банка.
