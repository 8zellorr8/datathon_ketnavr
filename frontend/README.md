# ForteLens — фронтенд

Интерфейс на HTML/CSS/JavaScript подключён к локальному Python API из `../backend`,
который вызывает анализатор из `../ai_service`.
Сборка и npm install не нужны. Библиотеки PDF и шрифты находятся в репозитории.

## Запуск

Из корня репозитория:

```powershell
cd ai_service
python Start-ForteBank.py
```

Открыть http://127.0.0.1:8001; локальная HttpOnly-сессия создаётся автоматически.
Служебный ключ API браузеру не передаётся. Выбрать MOV или MP4 меньше 64 МиБ, до 180 секунд,
затем нажать «Проверить видео». Модель остаётся на localhost.

Состояния: загрузка → обработка/очередь → результат либо ошибка.
При положительном результате открывается отчёт с 1–3 кадрами на событие,
таймкодами, описаниями и статусом источника. Доступен один PDF по всему отчёту.
Нормативное основание, которое не подтверждено, не выдумывается и требует проверки.
Отрицательный ответ относится только к настроенным категориям.

«Прекратить ожидание» прекращает опрос в браузере; серверная задача может продолжаться.
Новый файл, ошибка, отмена ожидания и новый анализ сбрасывают старый отчёт.

## Демо

http://127.0.0.1:8001/?demo=1 включает отдельные учебные примеры.
Загруженное пользователем видео всегда идёт в настоящий API; демо не является
запасным ответом при ошибке. Статический сервер на 8080 пригоден только для демо.

## Файлы

- `dist/analysis-client.js` — POST/GET с локальной сессией, опрос, ошибки и адаптация ответа API.
- `dist/app.js` — состояние, проверка результата, отчёт и маршруты.
- `dist/pdf-export.js` — локальная генерация PDF.
- `dist/index.html`, `styles.css` — форма, оформление и адаптивность.
- `dist/vendor/`, `assets/fonts/` — локальные библиотеки, шрифты и лицензии.

Точность модели не улучшена подключением интерфейса. Ограничения AI описаны
в `../ai_service/README.md`. Публичная публикация сайта — отдельный этап.
